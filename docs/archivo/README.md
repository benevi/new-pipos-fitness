# Archivo histórico

Documentos **anteriores a la reconstrucción** (Fases 0–5, ver [../PHASES.md](../PHASES.md)).
Se conservan por trazabilidad, **no describen el sistema actual** y no se mantienen:

- `PHASE_*_SUMMARY.md`: resúmenes de las «fases» 1–16 del proyecto original (worker BullMQ,
  coach de IA, panel admin, alimentos y comidas…), todo ello retirado o rehecho.
- `DECISIONS.md`: decisiones de diseño del proyecto original. Las vigentes están en los
  [ADR](../adr/README.md).
- `DB_STATUS_SUMMARY.md`, `E2E_VALIDATION_REPORT.md`: estado de la base de datos y de los e2e
  del esquema anterior (sustituido por la migración única de la Fase 3, ADR-0009).
- `FUTURE_TASKS.md`: lista de tareas del proyecto original. La deuda actual está en
  [../DEUDA_TECNICA.md](../DEUDA_TECNICA.md).

Para el estado actual: [README](../../README.md), [ARCHITECTURE](../ARCHITECTURE.md),
[SPEC_V1](../SPEC_V1.md), [MODELO_DATOS](../MODELO_DATOS.md) y [SECURITY](../SECURITY.md).
